01 / BAŞLANGIÇ

Hızlı başlangıç

Madium'da herkese açık dosyayı çekip pencereyi oluştur. Başka bilgisayarda readfile, yerel dosya veya GitHub token'ı gerekmez.

Madium · Luau
local Hutame = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/hutamev2/Hutame-libV2/main/dist/Hutame.lua"
))()

local Window = Hutame:CreateWindow({
    Title = "My Hub",
    Subtitle = "Welcome to your hub",
})
local Tab = Window:CreateTab("Main")
local Section = Tab:CreateSection("Actions")

Section:CreateButton({
    Name = "Test",
    Callback = function()
        Window:Notify({ Title = "Hazır", Content = "Buton çalıştı!" })
    end,
})
Yalnızca demoyu açmak içinloadstring(game:HttpGet("https://raw.githubusercontent.com/hutamev2/Hutame-libV2/main/dist/DemoHub.lua"))()
02 / KURULUM

İki çalışma yolu

↗

Madium

Yukarıdaki loadstring(game:HttpGet(...))() örneğini kullan. dist/Hutame.lua sadece kütüphaneyi döndürür; hub pencereni kendi kodun oluşturur.

▣

Roblox Studio

src/init.lua içeriğini ReplicatedStorage/Hutame adlı ModuleScript'e koy. Bir LocalScript içinden require ile yükle.

Studio · LocalScript
local Hutame = require(
    game:GetService("ReplicatedStorage"):WaitForChild("Hutame")
)
local Window = Hutame:CreateWindow({ Title = "My Hub" })

Madium'da gethui() uygun bir Instance döndürürse arayüz oraya eklenir; aksi halde PlayerGui kullanılır. Parent seçeneğiyle hedefi ayrıca belirleyebilirsin.

03 / REHBER

Pencere ve sekmeler

CreateWindow ana arayüzü oluşturur. Sekme ve bölümler içerik hiyerarşisini düzenler; bölüm başlığı daraltılabilir.

Pencere ayarları
local Window = Hutame:CreateWindow({
    Title = "My Hub",
    Subtitle = "Welcome",
    HubName = "Hutame Hub",
    ToggleKey = Enum.KeyCode.RightControl,
    Size = Vector2.new(660, 440),
    MinSize = Vector2.new(520, 340),
    MaxSize = Vector2.new(1280, 900),
    Resizable = true,
    AnimationDuration = 0.24,
    ConfigFolder = "HutameUI/MyHub",
    Theme = { Accent = Color3.fromRGB(152, 204, 255) },
})

local Tab = Window:CreateTab("Main")
local Section = Tab:CreateSection({ Name = "Actions", Collapsed = false })
Tab:Select()
Window:Show()Pencereyi göster
Window:Hide()Pencereyi gizle
Window:Toggle()Görünürlüğü değiştir
Window:Destroy()Arayüzü kaldır
Window:SetSearch("volume")Kontrolleri ara
Window:SetSize(Vector2.new(w, h))Boyutu ayarla
Window:GetSize()Boyutu al
Window:SetStatus("Ready")Alt durum metni

Tema anahtarları: Background, Sidebar, Surface, Hover, Border, Text, Muted, Accent. Tema pencere oluşturulurken verilir.

06 / API

Profiller ve kayıt

Flag tanımlı toggle, slider, dropdown, input ve keybind değerleri profillere eklenir. Persist = false kontrolü dışarıda bırakır.

Config API
Window:CreateConfigTab()             -- Hazır profil arayüzü
local json = Window:ExportConfig()   -- JSON string
Window:ImportConfig(json, true)      -- true: callback'leri atla
Window:SaveConfig("Default")          -- Mevcut dosyayı ezmez
Window:SaveConfig("Default", true)    -- Bilerek üzerine yaz
Window:LoadConfig("Default")
local names = Window:ListConfigs()
Window:DeleteConfig("Default")
Window:ResetConfig()

Dosya profilleri Madium'un dosya API'lerini kullanır. Studio'da ExportConfig / ImportConfig kullanılabilir; dosya işlemleri yoktur. Profil adı 1–48 karakter ve yalnız harf, rakam, alt çizgi veya tire içermelidir.

07 / ÖRNEKLER

Gerçek bir hub parçası

Aşağıdaki örnek bir ayarlar sekmesi, farklı bileşenler ve bildirim içerir.

Luau · Section API
local Settings = Window:CreateTab("Settings")
local General = Settings:CreateSection("General")

General:CreateToggle({
    Name = "Auto collect", Default = false, Flag = "AutoCollect",
    Description = "Toplama özelliğini aç",
    Callback = function(enabled) print("Enabled:", enabled) end,
})
General:CreateSlider({
    Name = "Speed", Min = 0, Max = 100, Increment = 5,
    Default = 25, Flag = "Speed",
    Callback = function(value) print("Speed:", value) end,
})
General:CreateDropdown({
    Name = "Mode", Options = { "Safe", "Fast" },
    Default = "Safe", Flag = "Mode",
})
General:CreateButton({
    Name = "Save", Style = "Primary", Compact = true,
    Tooltip = "Ayarları profile yazar",
    Callback = function()
        local ok, result = Window:SaveConfig("Default", true)
        Window:Notify({
            Title = ok and "Kaydedildi" or "Hata",
            Content = tostring(result), Duration = 4,
        })
    end,
})
08 / YARDIM

SSS ve ipuçları

Başka bilgisayarda readfile gerekir mi?

Hayır. Herkese açık raw.githubusercontent.com bağlantısı doğrudan indirilir; kullanıcı adı veya token gerekmez.

Hub neden kendiliğinden bir işlem yapmıyor?

Kütüphane yalnızca arayüz ve durum yönetimini sağlar. Oyun işlevlerini kendi Callback koduna bağlamalısın.

Bir ayarı nasıl kalıcı yaparım?

Kontrole benzersiz bir Flag ver, sonra SaveConfig veya hazır CreateConfigTab kullan. Studio'da JSON dışa/içe aktar.

Güncelleme hub'ımı etkiler mi?

main bağlantısı en güncel sürümü çeker. Sabit sürüm için URL'deki main yerine test ettiğin commit SHA'sını kullan.

Mobil destek var mı?

Ekrana göre ölçekleme ve dokunmatik etkileşimler bulunur. Ayrı bir mobil yerleşim henüz yoktur.
